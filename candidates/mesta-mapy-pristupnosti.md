## Try it
- **Map preview:** [samples/mesta-mapy-pristupnosti.geojson](../samples/mesta-mapy-pristupnosti.geojson): all 287 Brno buildings (name, type, rating, accessible WC, address). Ostrava and Hradec Králové are not included (licence unclear).
- **QGIS:** *Layer → Add Layer → Add ArcGIS REST Server Layer → New*:
  - Brno: URL `https://services6.arcgis.com/fUWVlHWZNxUvTUh8/arcgis/rest/services/mapa_pristupnosti_budovy/FeatureServer` (tested: 287 points), entrances `…/vstupy_budov/FeatureServer` (62 points).
  - Ostrava: URL `https://mapy.ostrava.cz/arcgisserver/rest/services/SMO_Pristupnost/mapa_pristupnosti/MapServer`, layer 8 "Kategorizace přístupnosti" (2,060 points, max 1,000 per request).
  - Hradec Králové: URL `https://geoportal.mmhk.cz/arcgis/rest/services/thematic_bariery`, services *nevidomi* (layers 1–4), *vozickari* (1–3), *neslysici* (1), *ost_objekty*. CRS EPSG:5514.
  - Opava: URL `https://mapy.opava-city.cz/server/rest/services/external` → *info_bezbarieroveobjekty_V*, *info_bezbarierovemhd_V*, *info_bezbarierovebudovy_V* (tested 2026-09-28: 162 + 268 + 50 + 210 polygons, 230 and 49 points; `…/MapServer/0/query?where=1%3D1&outFields=*&outSR=4326&f=geojson` returns GeoJSON).
  - Olomouc: no ArcGIS service; `curl -X POST -H 'Content-Type: application/json' --data '{"kodVrstvy":"bbo_upol"}' https://api.olomouc.eu/geo/ziskat-objekty` returns GeoJSON-like features (the `geometry` is wrapped in a list, so fix it before loading into QGIS); rating per object from `https://www.olomouc.eu/api/v1/objects?id=<id>` → `pristupnost.pristupnost` (pristupny / castecne / nepristupny).
- **Web:** Brno https://data.brno.cz/datasets/cca344ea2fb24eecb4e449c5970fd401_0, Ostrava https://mapy.ostrava.cz/mapa-pristupnosti/mapa/, Hradec Králové https://geoportal.mmhk.cz/mapa/mapa-bezbariery/, Opava https://mapy.opava-city.cz/portal/apps/webappviewer/index.html?id=2b8e08bd8ca24c16b5fc5f14ae80f0f0, Olomouc https://www.mapy.olomouc.eu/index.html#layerbbo

## Notes
- **Not known:** none of the three appears on Cs:Česko/freemap, Cs:Zdroje_v_jednani or in Sync `config.toml` (checked 2026-09-28). Cs:Import Mapy bez bariér imports the national POV project mapybezbarier.cz (castles, museums, churches); these city maps use the same methodology (Metodika kategorizace přístupnosti objektů, POV) but cover offices, surgeries, pharmacies, banks, shops and stops. The index of Czech accessibility maps at https://www.ostrava-bezbarier.cz/studie-rady-informace/mapy-pristupnosti-cr/ lists more cities (see open leads).
- **Brno (best source):** rich, current (198 records updated 2026), openly licensed. The healthcare records cover the whole city, the rest only the centre. The rating maps directly to wheelchair=yes/limited/no, the `wc` field to toilets:wheelchair. 171 of 287 already have some wheelchair-tagged OSM object within 30 m, but that radius is loose in the centre, so part of those 171 still lack the tag on the right object. The `GlobalID` is stable; suggested `ref:brno:pristupnost=<GlobalID>` if the community wants Sync.
- **Ostrava:** the largest set (2,060 rated points) but the layer has only rating + subcategory, no name; names and descriptions are on ostrava-bezbarier.cz pages that the WordPress API does not expose. Matching must be spatial against existing OSM POIs of the right type. The 1,066 stop ratings could fill wheelchair=* on highway=bus_stop / railway=tram_stop; only 74 of them have a wheelchair-tagged OSM object within 30 m.
- **Hradec Králové (blind-specific):** the only city layer found that records what blind people need: tactile elements and acoustic signals on 177 crossings, Braille/contrast notes on 72 stops, orientation voice beacons on 15 buildings (Terminál MHD 3 beacons, Krajský úřad 7…), guide lines on 321 route segments. But OSM in Hradec is already well mapped: 135 of the 139 surveyed crossings that have an OSM crossing within 25 m carry tactile_paving; only 10 crossings with tactile paving and 4 with acoustic signals are missing, and all 59 matched stops have tactile_paving. The added value is the voice beacons and the qualitative notes, not bulk tags. The project started before 2014 (Zlatý erb award that year); the city page says the map is updated continuously, but the layers carry no survey dates, so check on the ground.
- **Opava (second-best, round 7):** besides Hradec Králové, the only city layer found that surveys crossings for blind people, here across the whole town (528 crossings: 268 with tactile paving and guide line, 210 with one of the two, 50 with neither) plus all 230 stops and 162 ZTP bays. OSM in Opava has 695 crossing objects in the centre, only 218 with tactile_paving, and 14 disabled-parking objects. Crossing mapping: `DLAZBA` 2 = tactile paving present (259 + 157 records), 1 = present only partly (36), 0 = none (76); `VODLINKA` 1 = guide line. Stops map to wheelchair=yes/limited/no on highway=bus_stop plus `ZvysenaHrana` (raised kerb, no well-established OSM key; kerb:height exists on kerb nodes). Buildings carry the RÚIAN address code, which makes matching reliable. `OBJECTID` is the only ID; ask the city whether it is stable.
- **Olomouc (small):** 127 objects, but 51 are Palacký University buildings (faculties, libraries, dormitories) that no other source rates, and 55 records were edited in 2025–2026. The web page says the survey is done by the city's Bezbariérová Olomouc programme (https://prorodinu.olomouc.eu/pristupnost/pristupnost-objektu). Numeric object `id` is stable across both APIs.
- **Checked and not added:** Pardubice (https://mapy.pardubice.eu/MyCity/bez_bariery, surveyed by Česká abilympijská asociace): 209 objects (123 přístupný, 62 částečně, 28 nepřístupný) only as HTML list pages from `MyCity/AsyncJSON.ashx` (action `static_search`, window `bez_bariery`, 43 pages); no coordinates (location only via a Marushka query), and every dated record was checked 2014–2016. České Budějovice (http://bezbarier.c-budejovice.cz/mapa/): 130 Google Maps markers with a 3-level icon, but stale (still lists GE Money Bank and Era – poštovní spořitelna, both gone for years). IPR Praha "Vybrané bezbariérové trasy" (https://gp-dc.iprpraha.cz/arcgis/rest/services/app_dop/mapapristupnosti/FeatureServer/1): only 16 polylines with a number and provider, no attributes; layer 0 of the same service is covered by prague-ipr-stani-ztp.md. Plzeň: the link on the index goes to the Marushka portal https://gis.plzen.eu/sluzby/, no accessibility layer or REST service found (`/arcgis/rest/services` returns 404).
- **Open lead:** presbariery.cz (Pražská organizace vozíčkářů, Prague district accessibility maps, © POV z. s.): markers are loaded by the Joomla component com_zhgooglemap and were not extracted; check overlap with the POV data already covered by Cs:Import Mapy bez bariér before going further.
- **Voice beacons in general:** No public list of installed orientation voice beacons was found from SONS, the Centrum pro nevidomé pages on VPN transmitters, or the manufacturers. Hradec Králové's 15 flagged buildings are the only machine-readable record found.
- **Licence:** Brno CC BY 4.0 → consent from Magistrát města Brna, Odbor zdraví (named as author in NKOD). Ostrava: ask Magistrát města Ostravy / Bez bariér Ostravsko (poradenství bez bariér). Hradec Králové: ask Magistrát města Hradec Králové, odbor sociálních věcí a zdravotnictví (named on the Bezbariérový Hradec page as the organiser). Opava: ask Magistrát města Opavy, GIS (the portal publishes the layers) and the Bezbariérová Opava project (bbopava.cz). Olomouc: ask Magistrát města Olomouce, Bezbariérová Olomouc (prorodinu.olomouc.eu).
- Wiki pages read: Key:wheelchair, Key:tactile_paving, Key:traffic_signals:sound, Key:blind, OSM for the blind, Cs:Import Mapy bez bariér.
